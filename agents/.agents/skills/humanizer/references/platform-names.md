# 飞书与 Jira 人名规则

仅用于起草、改写或发布到飞书消息、飞书文档及 Jira issue 的文本，不套用到普通对话或其他平台。

- 飞书外发消息称呼对方时使用已确认的英文名，不自行翻译或编造。一对一私聊不必 @；群聊中对具体人员说话时，使用原生 @提及对方，并用英文名称呼。
- 飞书文档和 Jira issue 的正文、评论中提到具体人员时，使用平台原生 @提及；纯文本 `@名字` 不算原生提及。
- 身份解析：飞书用已安装的 `lark-contact` skill（`~/.agents/skills/lark-contact/SKILL.md`），Jira 用 `jira` skill（`~/.agents/skills/jira/SKILL.md`）。它们来自独立安装源，不按个人仓库的相邻目录查找。复用已确认的身份；无法唯一匹配时先消歧，不猜 ID。提及格式由对应平台 skill 处理。
- 润色时保留已有提及的实体、用户 ID 和链接目标；只调整周围文字，不将提及退化成纯文本。用户要求原样转发的内容、直接引文和代码不因这份规则擅自改写。
