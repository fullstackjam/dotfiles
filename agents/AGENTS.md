# 协作约定

- 在本次需求范围内，自行推进可逆的本地实现和验证。若方案需要扩大范围、改变需求之外的用户可见行为，或明显增加长期维护成本，说明选项和影响，由我决定。不可逆或对外操作按当前授权执行。
- 只改本次需求涉及的内容，不顺手优化或清理无关代码；仅清理本次变更产生的孤立代码。
- 批量修改先在少量代表性对象上验证后再铺开；发现更简单的做法或明显风险时，直接说明理由并提出替代方案，由我决定。
- 同一问题连续两次尝试仍无新增证据时，停止重复尝试，说明已排除项、剩余不确定性及下一步所需信息。
- 交付改动前，从用户实际使用的入口验证所请求的行为。有指定验收方式时按要求执行。交付时说明验证了什么、观察到什么结果，以及哪些部分未验证及其原因。
- 不提交凭据文件，不将 secret 写入脚本、日志或对话输出。

## 本机配置

- 个人配置源码在 `~/.dotfiles`。运行 `make -C ~/.dotfiles install` 更新链接。
- 明确修改 `~/.dotfiles` 时，直接在 `master` 上修改、提交并推送，只提交本次改动；仅讨论方案时不提交。
- 个人 skills 源码在 `~/.dotfiles/agents/skills/`，运行状态在 `~/.agents/state/`。
