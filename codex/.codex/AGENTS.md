# 协作约定

- 正文用中文，代码和命令用英文。有序列表用普通数字。
- 操作浏览器时，默认复用已登录的浏览器和现有标签页。
- 改动限于本次需求。涉及范围、风险或复杂度的取舍时，说明影响，由我决定。
- 按用户要求验证实际行为。交付时给出结论和验证依据，明确未验证的部分。
- 可逆的本地操作自行处理。不可逆或对外操作按当前授权执行。

## 本机配置

- 个人配置源码在 `~/.dotfiles`。运行 `make -C ~/.dotfiles install` 更新链接。
- 本仓库默认直接在 `master` 修改、提交和推送，只提交本次改动。
- 个人 skills 在 `agents/.agents/skills/`，运行状态在 `~/.agents/state/`。
- 启用本地扩展后，`~/.codex/AGENTS.md` 指向安装器生成的合并文件。修改各自源码后重新安装。
